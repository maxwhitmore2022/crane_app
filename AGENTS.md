# Project Layout

This is a single-file web app. `index.html` is at the top level so GitHub Pages can serve it directly.

Keep project files in the following locations:

- `index.html`, `AGENTS.md`, `spec.md`, and `prompts.md` stay at the top level.
- `00_planning/` contains planning notes and sketches.
- `01_data/` contains data files.
- `02_validation/` contains hand calculations and test cases.
- `03_output/` contains screenshots and exported results.

## File Placement Rule

Save every new file in the folder that matches its purpose. Do not place additional project files in the repository root. Keep each numbered folder organized and add to its `README.md` only if the existing folder description needs clarification.
